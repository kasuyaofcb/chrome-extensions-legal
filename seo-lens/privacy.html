Privacy Policy

Extension: SEO Lens · Last updated: September 24, 2026

Data collection

This extension collects nothing. It has no server. Nothing you audit leaves your browser.

What the extension does

When you start an audit, the extension fetches the pages of the site you entered and sends an HTTP request to each link and image found on those pages in order to read its status code. It also looks for robots.txt, sitemap.xml and llms.txt on that site.

These requests go directly from your browser to the site being audited. They do not pass through any server operated by the developer, because no such server exists.

Data we collect

None. Specifically, the extension does not collect, transmit, or sell:

  • personally identifiable information
  • health information
  • financial or payment information
  • authentication information
  • personal communications
  • location
  • web history
  • user activity
  • website content

Data stored on your device

The extension stores one value locally, using the browser's extension storage:

  • the last URL you audited, so the form can be pre-filled next time

This value never leaves your browser. Removing the extension removes it.

Permissions

  • Host access (requested at run time, not at install time) — required to fetch the pages you ask to audit, along with that site's robots.txt, sitemap.xml and llms.txt, and to check the status of the links and images on those pages. The site is not known in advance, so access cannot be restricted to a fixed list of hosts.
  • tabs — used only to read the URL of the active tab, so the audit form can be pre-filled with the page you were looking at.
  • storage — used only for the single value described above.

Cookies

No cookies are sent with any request the extension makes. Every request — the pages it audits, robots.txt, sitemap.xml, llms.txt, and the status checks on links and images — is made without credentials.

This is deliberate. Search engines are not logged in, so the anonymous view of a page is the one that matters for an audit. It also means the extension cannot act on your behalf on a site where you happen to be logged in.

Third parties

There are none. The extension contacts no analytics service, no API, and no backend of ours. It uses no trackers and no advertising networks.

Changes to this policy

If this policy is updated, the "Last updated" date at the top will change. Material changes will also be noted in the extension's release notes on the Chrome Web Store.

プライバシーポリシー

拡張機能: SEO Lens · 最終更新: 2026年9月24日

データ収集について

この拡張機能は何も収集しません。サーバーを持ちません。監査した内容がブラウザーの外に出ることはありません。

本拡張機能の動作

監査を開始すると、本拡張機能は入力されたサイトのページを取得し、そのページ上で見つかった各リンクと画像に対してHTTPリクエストを送信してステータスコードを読み取ります。あわせて、そのサイトの robots.txt、sitemap.xml、llms.txt を探します。

これらのリクエストは、お使いのブラウザーから監査対象のサイトへ直接送信されます。開発者が運用するサーバーを経由することはありません。そのようなサーバーは存在しないためです。

収集しないデータ

何も収集しません。具体的に、本拡張機能は以下を収集・送信・販売しません:

  • 個人を識別できる情報
  • 健康情報
  • 金融・決済情報
  • 認証情報
  • 個人間の通信内容
  • 位置情報
  • 閲覧履歴
  • ユーザーの操作履歴
  • ウェブサイトのコンテンツ

端末に保存されるデータ

本拡張機能は、ブラウザーの拡張機能ストレージを使って、次の1つの値のみをローカルに保存します:

  • 最後に監査したURL（次回フォームに初期値として入れるため）

この値がブラウザーの外に出ることはありません。拡張機能を削除すれば、この値も削除されます。

権限の利用目的

  • ホストへのアクセス（インストール時ではなく実行時に要求） — 監査を指示されたページと、そのサイトの robots.txt / sitemap.xml / llms.txt を取得し、ページ上のリンクと画像の状態を確認するために必要です。対象サイトは事前に分からないため、特定のホストに限定することができません。
  • tabs — 現在開いているタブのURLを読み取り、監査フォームの初期値にするためだけに使用します。
  • storage — 上記の1つの値の保存のためだけに使用します。

Cookie

本拡張機能が送信するすべてのリクエストは、Cookieを伴いません。監査対象のページ、robots.txt、sitemap.xml、llms.txt、リンクと画像の状態確認 — そのいずれも認証情報なしで送信されます。

これは意図的な設計です。検索エンジンはログインしていないため、監査において意味を持つのは匿名の状態で見えるページです。また、あなたがログインしているサイトに対して、本拡張機能があなたの代わりに何かを実行することもありません。

第三者サービス

第三者サービスは一切使用していません。分析サービス・API・開発者側のバックエンドのいずれにも接続しません。トラッキングや広告ネットワークも使用していません。

ポリシー変更について

本ポリシーが更新された場合、冒頭の「最終更新」の日付が変更されます。重要な変更は Chrome Web Store のリリースノートにも記載します。
